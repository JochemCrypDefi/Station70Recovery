# Phase-2 (transaction building) dependencies -- OPTIONAL.
#
# Only install these if you intend to use `s70 inspect` / `s70 sign`.
# They are pinned exactly: every one of these SDKs has made breaking changes
# in the last year, and a recovery tool is the wrong place to discover that.
#
# These are NOT needed to recover a private key or to import it into a
# browser extension. Keep them off the offline signing machine if you can --
# fewer moving parts near a private key is better.
#
# Install into a SEPARATE virtualenv from requirements.txt if you hit
# resolver conflicts (solana-py pins a narrow solders range).
#
# Note there is no Sui SDK here. Sui signing is implemented directly against
# its published signing scheme (blake2b over intent-prefixed bytes, then
# Ed25519), with the `sui` CLI building the transaction. See
# s70/txn/sui_tx.py for why.
